# AI 应用开发 · 学习文档集

> 面向：2026 届求职 AI 应用开发 / Agent 工程师，Java 背景、Python 能读能改。
> 特点：**每份文档都绑定本项目的真实文件与真实数字**，不是通用教程；读完能直接用于面试。

## 怎么用

1. 先读 `00-学习路线与14天计划.md`，按天执行；
2. 每个主题文档的结构统一：**核心概念 → 本项目实践 → 面试追问 → 自测题 → 练习**；
3. 面试前 1 天只看 `09-面试速查卡.md`；
4. 遇到不懂的代码，直接打开文档里标注的文件对照读。

## 前置认知

- 项目 = Java 业务底座 + Python AI 层 + Vue 前端，三个独立进程，通过 HTTP 通信；
- AI 服务（`ai-service/`）不直连数据库，身份只从 token 解析，写操作必须用户确认；
- 所有效果数字都可以用仓库里的脚本复现（这是你最大的底气）。

## 学习原则

1. **概念优先于语法**：先讲清"为什么"，再看代码"怎么做"；
2. **每个知识点都要能落到一个文件/一次实验**，避免空泛；
3. **能复述才算学会**：每份文档末尾的自测题，能不看答案讲出来再进入下一份。
