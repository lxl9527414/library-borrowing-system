## F. 常见翻车点（提前避开）

| 翻车 | 原因 | 预防 |
|---|---|---|
| 面试官 clone 跑不起来 | 没写清前置依赖 | README「快速开始」用 `dev_up.sh` 一条命令；已注明需要 JDK17/Node20/Redis |
| 演示时 AI 回"开场白" | 没配 Key 走了 mock | 演示前确认徽标是 `deepseek`；若用 mock 主动说明 |
| 端口冲突 | 18080/5173 被占用 | `lsof -ti :18080 :5173 \| xargs kill` |
| 页面打不开 | 直接用 18080 访问 /chat（AI 未代理） | 用 `localhost:5173`，或 nginx 配 `/api/ai/` |
| 数据库脏数据 | 演示借书没还 | 演示脚本自动归还；手动演示后点"还书" |
| CI 红 | 依赖/环境差异 | push 后第一时间看 Actions，红就修 |
