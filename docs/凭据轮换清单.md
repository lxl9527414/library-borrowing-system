## 2. 轮换步骤（以管理员密码为例）

```bash
# ① 生成本地 bcrypt 哈希（不要用明文存库）
#    项目已有 spring-security-crypto，可用任意 JDK 环境跑一段小脚本，或用 Python bcrypt：
python3 -c "import bcrypt;print(bcrypt.hashpw(b'你的新密码', bcrypt.gensalt(rounds=10, prefix=b'2b')).decode())"
# → $2b$10$....

# ② 更新线上数据库（示例：服务器上执行，密码从环境变量读，不要写进命令历史）
mysql -uroot -p"${MYSQL_ROOT_PASSWORD}" library_db \
  -e "UPDATE sys_user SET password='${NEW_HASH}' WHERE username='admin';"

# ③ 更新部署环境文件
sudo vi /opt/library/config/library.env     # DB_PASSWORD / REDIS_PASSWORD / AI_INTERNAL_TOKEN
sudo systemctl restart library-server

# ④ 更新本地开发环境（.env，gitignored）
#    DEMO_USER / DEMO_PASSWORD / AI_INTERNAL_TOKEN ...
bash scripts/dev_down.sh && bash scripts/dev_up.sh

# ⑤ 更新凭据备忘（本地文件，gitignored）
#    cp deploy/credentials.local.example deploy/credentials.local 然后填入新值
#    确认：git check-ignore deploy/credentials.local  有输出即被忽略
```

**其他账号**：MySQL/Redis 需要用各自的方式改（`ALTER USER ... IDENTIFIED BY`、`redis-cli CONFIG SET requirepass`），
改完都要同步 `library.env` 与 `deploy/conf/*`。

## 4. 长期治理（建议）

| 项 | 现状 | 建议 |
|---|---|---|
| 凭据存放 | 服务器 `/opt/library/config/library.env`（systemd `EnvironmentFile`） | 保持；不要写进代码/镜像 |
| 本地凭据 | `.env`（gitignored）+ 可选 `deploy/credentials.local` | 只放开发账号，禁止放生产密码 |
